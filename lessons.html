📚 What We'll Cover

1. Database Fundamentals

  • What is a Database? Persistent data storage and retrieval
  • Types of Databases:
    • SQL (Relational): MySQL, PostgreSQL, SQLite - Structured, table-based
    • NoSQL (Non-Relational): MongoDB, Firebase - Flexible, document-based
  • CRUD Operations: Create, Read, Update, Delete - the four basic operations

2. Relational Databases (SQL)

  • Tables, Rows, and Columns
  • Primary Keys and Foreign Keys
  • Relationships between tables (One-to-Many, Many-to-Many)
  • Data Types and Constraints
  • Introduction to SQL queries:
    -- Basic SELECT query SELECT * FROM users WHERE status = 'active'; -- INSERT query INSERT INTO users (name, email) VALUES ('John', 'john@example.com'); -- UPDATE query UPDATE todos SET completed = true WHERE id = 5; -- DELETE query DELETE FROM todos WHERE id = 5;

3. NoSQL Databases (MongoDB)

  • Documents and Collections
  • JSON-like Data Structure
  • Schema Flexibility
  • Querying with JavaScript objects:
    // MongoDB query example db.todos.find({ userId: 5 }); // Insert db.todos.insertOne({ title: 'Learn DB', completed: false }); // Update db.todos.updateOne({ _id: 123 }, { $set: { completed: true } }); // Delete db.todos.deleteOne({ _id: 123 });

4. Choosing a Database for Your Project

  • SQL When: Complex relationships, structured data, strong consistency needed
  • NoSQL When: Flexible schema, rapid development, scalability is priority
  • For Our To-Do App: We'll use MongoDB for simplicity and speed of development

🔗 Connecting Databases to Node.js

Database Drivers & ORMs

To connect from Node.js to a database, we use drivers or ORMs:

  • For SQL: Sequelize, TypeORM, Knex.js
  • For MongoDB: Mongoose (the industry standard)

Simple Node.js to Database Flow

// 1. Import Mongoose const mongoose = require('mongoose'); // 2. Connect to MongoDB mongoose.connect('mongodb://localhost/mydb'); // 3. Define a schema and model const todoSchema = new mongoose.Schema({ title: String, completed: Boolean, createdAt: Date }); const Todo = mongoose.model('Todo', todoSchema); // 4. Use the model Todo.create({ title: 'Learn Databases', completed: false });

💾 Data Normalization (SQL Concept)

Organizing data efficiently to avoid redundancy:

  • 1NF (First Normal Form): Atomic values, no repeating groups
  • 2NF (Second Normal Form): Remove partial dependencies
  • 3NF (Third Normal Form): Remove transitive dependencies
Example: For our To-Do App:
Users Table: id, username, email, password
Todos Table: id, title, completed, userId (references Users)

🎯 Why This Matters for Our To-Do App

Understanding databases is crucial because:

  1. Data Persistence: Todos need to survive server restarts
  2. User Data: Each user has their own todos - requires relationships
  3. Scalability: As users increase, database efficiency matters
  4. Security: Proper database design protects user data

Our To-Do App Database Schema

// MongoDB Collection: todos { _id: ObjectId, userId: ObjectId, // Link to user title: String, // Todo title description: String, // Optional details completed: Boolean, // Status priority: String, // high/medium/low dueDate: Date, // When it's due createdAt: Date, // Timestamp updatedAt: Date // Last modified }
